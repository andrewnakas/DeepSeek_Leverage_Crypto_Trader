# 🚀 Quick Start - Get Trading in 2 Minutes!

## The Fastest Way to Start (FREE)

### Step 1: Get FREE API Key (30 seconds)

**Option A - OpenRouter (Recommended)**
1. Visit: https://openrouter.ai
2. Click "Sign In" with Google/GitHub
3. Go to: https://openrouter.ai/keys
4. Click "Create Key"
5. Copy your key ✅

**Option B - Groq (Super Fast)**
1. Visit: https://console.groq.com
2. Sign up with Google/GitHub
3. Get API key from dashboard
4. Copy your key ✅

**Option C - Run Locally (100% FREE Forever)**
```bash
# Install Ollama
curl -fsSL https://ollama.com/install.sh | sh

# Download model
ollama pull deepseek-r1:7b

# Start server
ollama serve
```

### Step 2: Open Trading Bot

Visit: https://andrewnakas.github.io/DeepSeek_Leverage_Crypto_Trader/

Or run locally:
```bash
cd /path/to/DeepSeek_Leverage_Crypto_Trader
python -m http.server 8000
# Open: http://localhost:8000
```

### Step 3: Configure (1 minute)

1. **Select AI Provider** from dropdown:
   - OpenRouter (easiest)
   - Groq (fastest)
   - Ollama (local & free forever)

2. **Enter API Key** (or skip for Ollama)

3. **Set Your Preferences:**
   - Starting Balance: $10,000 (adjust as needed)
   - Analysis Interval: 15 minutes (recommended)
   - Max Leverage: 10x (safe for testing)
   - Risk Per Trade: 5% (balanced)

### Step 4: Start Trading!

1. Click **"Start Trading Bot"** 🚀
2. Watch real-time analysis appear
3. See positions open automatically
4. Monitor your portfolio grow!
